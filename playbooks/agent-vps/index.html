Most servers are “secured” with a firewall and a strong password. Then a test database, an old admin page or a Docker port ends up on the internet anyway.

This playbook takes a different route: nothing on the server answers the public internet. Websites reach it through a Cloudflare tunnel the server opens from the inside. You reach it through Tailscale, from your own laptop and phone. No open ports, no SSH on port 22, no door to knock on.

It is not a blog post or a course. It is one Markdown file, written for your agent, not for you. Each phase has a goal, the commands, a check that must pass and a rollback. Where only you can decide or log in, the agent stops and asks you.

What your agent will set up

  • 0. Safety rulesA dead-man switch: risky changes undo themselves unless the agent confirms it can still get in.
  • 1. Audit firstRead-only: what is running, what is open, what the target state is.
  • 2. TailscaleYour private way in. SSH only from your own devices.
  • 3–4. Firewall and SSHPublic SSH closed, password login off, and why a custom port does not help.
  • 5. Cloudflare TunnelWebsites stay online without an open port. Including a live site move with zero downtime.
  • 6. Cloud firewallA second lock at the provider, so one mistake on the server does not reopen it.
  • 7. Docker rulesThe Docker port trap that bypasses your firewall, and how to avoid it.
  • 8. UpdatesFour update streams, reboots, a monthly checklist and an alert when patches lag.
  • 9. Backups and alerts3-2-1 backups, memory protection, and rules for several agents on one server.
  • 10. Final checkA scan from outside that must show nothing open, reported to you as a checklist.

Plus: a cloud-init setup for a new server that is never exposed at all, and how to choose a Hetzner server type.

Questions

Which agents does it work with?
Any agent that can run shell commands on the server: Claude Code, Codex, Cursor’s agent, or a human who copies commands carefully.
Which provider?
Written for and used on Hetzner Cloud with Ubuntu LTS. Most of it works on any Linux VPS; the provider-specific parts are marked. Server prices: see Hetzner’s own price list.
Do I need Cloudflare and Tailscale?
Yes. Both have free plans that cover this setup. Your domain needs to be on Cloudflare.
What does “early access” mean?
The playbook runs on my own servers today. Before v1.0 a fresh agent sets up a brand-new server with nothing but this file, and whatever it stumbles on gets fixed. You get that version, and every one before it, for free.
What does it not cover?
The security of your own apps: logins, rate limits, outdated frameworks. A closed server still serves a bad login to every visitor. Check your apps, not just your firewall.
Can I share it?
For your own servers and your own clients’ servers, yes. Please don’t republish or resell the file.
