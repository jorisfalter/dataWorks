How AI changed
my spending

What I stopped paying for, what I still pay for, and where the money goes now.

By Joris Falter · Lilongwe · October 2026

I don’t spend less. I spend it somewhere else. Things I used to rent from platforms, I now build and run myself, with AI doing most of the work.

Over the last months I moved almost everything I run onto my own server, with Claude Code doing the migrations: reading the old app, writing a Docker setup, moving the secrets, switching DNS. This is the honest list.

1. Hosting: four platforms out, one server in

Heroku
Fly.io
Render
Vercel
→ Hetzner

Heroku was about $15 a month for 13 apps. Fly was $30 in one month across 11 apps, mostly an n8n machine nobody had switched off: “turning it off” never actually stopped the billing. Now it all runs on Hetzner.

2. Analytics: paid out, self-hosted in

Google Analytics, Simple Analytics and Plausible are gone. Since September I run Umami on my second server, next to Cloudflare Web Analytics, which is free. One dashboard for all my sites, both cookieless, so no consent banner.

3. Smaller things I dropped

Was usingNow
n8n, Make.comClaude Code + cron jobs on my server
MongoDB AtlasStatic files and SQLite
MapboxMapLibre + OpenFreeMap (free)
Ahrefs / SemrushOpenSEO + DataForSEO, about $0.40 a run
PowerPointHTML slides
Video editing softwareffmpeg + Remotion, Adobe Podcast for audio
Mac utility appsSmall tools I built: fan control, keyboard lock

That first line surprised me most. I used to teach Make.com and still review n8n workflows for clients. For my own work, a scheduled script that Claude Code writes and maintains is now simpler.

4. What I kept, and why

Slack
Airtable
Campfire
  • Slack, because my clients and some of my communities already work there. I join them.
  • Airtable runs some of my automations, and the interface is easy to work with.
  • Campfire for when I hire people myself: a one-time purchase that runs on my own server.

5. Where the money goes now

Claude
OpenAI

AI tools. Claude Code does the building and the server work. This is the line that went up; everything above went down.

Hardware, because building got easier. With AI I can do the software side of a hardware project in an evening, so I buy things I wouldn’t have bought before: a Bambu A1 mini 3D printer (city maps, puzzles, parts for my own projects), a Raspberry Pi Zero 2 W that streams Spotify to a speaker all day, and a T-shirt store, simply because setting one up is easy now.

Two servers. Everything runs on two Hetzner servers in Germany and Finland, connected to my laptop and phones over Tailscale. Public sites go out through a Cloudflare tunnel; nothing private is open to the internet.

6. Where the time goes now

YouTube is free to use. I invest in it with time instead: recording, editing, publishing. AI does the editing: cutting silences, captions, thumbnails and audio fixes, without editing software.

7. What might go next

My MacBook, maybe for Linux: most of my work now happens in a terminal and on a server. My iPhone and Pixel are both staying for now.

In short

Fewer platforms, more open-source tools, less paid software. More AI and hardware. The total is about the same, probably a bit more. It just goes somewhere else now.
